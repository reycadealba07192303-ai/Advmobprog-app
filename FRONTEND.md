# Frontend — `estrellon_mobile/`

Flutter app folder (same role as `robles_mobile` in the lab reference).

```
estrellon_mobile/
├── lib/
│   ├── main.dart
│   ├── constants.dart
│   ├── models/       article_model.dart, user_model.dart
│   ├── services/     article_service.dart, user_service.dart
│   ├── providers/    theme_provider.dart, user_provider.dart
│   ├── screens/      splash, login, home, article, detail, settings
│   ├── widgets/      add_article_dialog, custom_text, ...
│   └── utils/          loading.dart, article_helpers.dart
├── assets/
├── pubspec.yaml
└── .env                HOST=http://localhost:5000
```

Open **`estrellon_mobile`** in VS Code / Cursor to work on the Flutter app.
